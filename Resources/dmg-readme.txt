Pdf2Score — 把 PDF 樂譜轉成 MuseScore 可以開的檔案
==================================================

安裝
----
1. 把左邊的 Pdf2Score 拖到右邊的「應用程式」資料夾。
2. 打開「應用程式」資料夾，在 Pdf2Score 上按 右鍵 → 打開。
3. 會跳出「無法驗證開發者」之類的警告，按「打開」或「完成」。

如果第 3 步只給你「移到垃圾桶」而沒有「打開」的選項：
  打開「系統設定」→「隱私權與安全性」，往下捲到最下面，
  會看到一行「已封鎖 Pdf2Score」，按旁邊的「仍要打開」。

這個步驟只需要做一次。之後就可以正常雙擊開啟。

為什麼會有警告？因為這個 App 沒有向 Apple 付費購買開發者憑證做公證，
不是因為它有問題。


使用
----
把 PDF 樂譜拖進視窗（可以一次拖很多個，或整個資料夾），按「開始轉換」。
每份 PDF 會在原本的資料夾裡產生一個同名的 .mxl 檔，用 MuseScore 打開即可。

多頁的 PDF 會自動接成一份完整的譜。

轉出來不理想？在那一列按右鍵，選「改用 ⋯ 重新辨識」，
換另一個辨識引擎再跑一次。兩個引擎的強項不同，
換一個常常就好了——這比調設定有效得多。


需要知道的事
------------
* 需要 macOS 14（Sonoma）以上。Apple Silicon 和 Intel 的 Mac 都可以，
  但兩種機型的安裝檔不一樣：
    Pdf2Score-AppleSilicon.dmg  → 晶片寫 Apple M1／M2／M3⋯ 的 Mac
    Pdf2Score-Intel.dmg         → 晶片（或處理器）寫 Intel 的 Mac
  在蘋果選單 →「關於這台 Mac」可以看到自己是哪一種。
  拿錯的話 App 會打不開。
* 不需要另外安裝 Python 或任何東西，也不需要網路。
* Apple Silicon 一頁大約 5 秒；Intel 機型明顯較慢，估計一頁 15 秒上下。
* 樂譜辨識不可能百分之百正確，轉出來的譜「一定要在 MuseScore 裡校對」。
  掃描歪斜、手寫譜、複雜的鋼琴譜錯誤會比較多。
  這個工具是幫你省下重新輸入的功夫，不是免校對。
