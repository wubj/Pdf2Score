# Third-party components

Pdf2Score is distributed under the **GNU Affero General Public License v3.0**
(see [LICENSE](LICENSE)). That is not a free choice: the two recognition engines
it embeds are themselves AGPL-3.0, so the combined work must be too.

Nothing in this repository is a copy of these projects. `Tools/build_runtime.sh`
and `Tools/fetch_audiveris.sh` download them at build time from their official
release channels; the versions below are what a build produces today.

## Recognition engines

| Component | Version | License | Source |
|---|---|---|---|
| homr | 0.7.0 | AGPL-3.0 | https://github.com/liebharc/homr |
| Audiveris | 5.11.0 | AGPL-3.0 | https://github.com/Audiveris/audiveris |

Audiveris ships with its own bundled OpenJDK runtime and Tesseract OCR; their
licenses (GPL-2.0-with-Classpath-exception and Apache-2.0 respectively) apply to
those parts, and the notices inside `Audiveris.app` are preserved as-is.

## Python runtime

The app embeds a relocatable CPython from
[python-build-standalone](https://github.com/astral-sh/python-build-standalone)
(PSF License, plus the licenses of the libraries CPython links), with these
packages installed into it:

| Package | Version | License |
|---|---|---|
| onnxruntime | 1.29.0 | MIT |
| opencv-python-headless | 4.14.0.94 | Apache-2.0 |
| numpy | 2.5.2 | BSD-3-Clause (and 0BSD, MIT, Zlib for vendored parts) |
| Pillow | 12.3.0 | MIT-CMU |
| pypdfium2 | 5.13.0 | BSD-3-Clause / Apache-2.0 (PDFium: BSD-3-Clause) |
| rapidocr | 3.9.2 | Apache-2.0 |
| requests | 2.34.2 | Apache-2.0 |
| musicxml | 1.4 | see https://pypi.org/project/musicxml/ |
| typing_extensions | 4.16.0 | PSF-2.0 |
| shapely | 2.1.2 | BSD-3-Clause |

The Intel build pins `onnxruntime==1.23.2`, the last release with a macOS x86_64
wheel — see `Resources/python/requirements-x86_64.txt` for why.

## Fonts and assets

The app icon (`Resources/AppIcon.icns`) is generated by `Tools/make_icon.py` and
is part of this project. The user guide in `docs/` links the Google Fonts
families Fraunces, Source Sans 3, JetBrains Mono, Noto Sans TC and Noto Serif TC,
all under the SIL Open Font License 1.1; they are loaded from Google's CDN and
not redistributed here.

The sample scores in `samples/` are randomly generated note sequences, engraved
with MuseScore purely as test fixtures. They are not anyone's music.
